# Data contract

- **Engine and data pair.** Microcosm UK 2024-25 national build `uk-frs-calibration-attempt-20261112T133744Z-6f918b81` (SHA-256 `e268e3af7932784ad4471f008097a5acc6c3c5bc15c4c54fbb5a489b2a0ac9ae`, Hugging Face dataset `policyengine/populace-uk-private`) with policyengine-uk 2.177.7 and policyengine-core 3.34.10, the versions it was built and certified on (`data_build.DATA_BUILD`). No policyengine.py release covers the pair, so simulations load policyengine-uk directly and refuse another file or engine version. G0 records the pair, and every figure carries "build uk-frs-calibration-attempt-20261112T133744Z-6f918b81, policyengine-uk 2.177.7, not in a policyengine.py release".
- **Microdata stay private.** No `.h5` file, record-level extract or weight is committed (`.gitignore`, `scripts/check_public_data.py`). `scripts/youth_base_check.py` prints weighted totals for the team only.
- **Columns the measures read:** `age`, `employment_status`, `current_education`, `is_in_approved_training`, `is_in_non_advanced_education`, `employment_income`, `self_employment_income`, `hours_worked`, `universal_credit_reported`, `is_disabled_for_benefits`, `pip_dl_points` and `pip_m_points` (builds 9e18f010 and 6f918b81 store points and no award category; policyengine-uk derives the categories), `region`, `rent`, `tenure_type`.
- **Columns the measures need but the data lack:** work history, NEET status and duration, Work Capability Assessment outcome or UC conditionality group, care-leaver status, employer records and hiring flows. The pinned build stores `is_apprentice` only as a flag drawn at ages 21-24 for the employer NICs apprentice relief (237 Microcosm rows from 34 distinct survey households on 6f918b81; about 130k people weighted on eeb6093e): fit for a national score of that relief, which on eeb6093e came out about 28% short of HMRC (£0.27bn against £0.37bn in 2024-25), and not for describing apprentices, other ages or sub-national areas (#6).
- **Heavy runs.** Run one data-loading job at a time and check available memory first. Prefer reading the needed columns to full simulations. The national file holds about 78k household rows from about 16k survey households, and its memory use cannot be cut much by trimming the file; the practical fix is one year per run (María, data owner, 13 November 2026). `model-run` has no per-year option yet.
