# Data contract

- **Engine and data pair.** Microcosm UK 2024-25 national build `uk-frs-calibration-attempt-20261110T204756Z-9e18f010` (SHA-256 `adb6204d0af5e08a42cccec81250ce116518687f964e31c654a17d658b3416e8`, Hugging Face dataset `policyengine/populace-uk-private`) with policyengine-uk 2.177.7 and policyengine-core 3.34.10, the versions it was built and certified on (`data_build.DATA_BUILD`). No policyengine.py release covers the pair, so simulations load policyengine-uk directly and refuse another file or engine version. G0 records the pair, and every figure carries "build uk-frs-calibration-attempt-20261110T204756Z-9e18f010, policyengine-uk 2.177.7, not in a policyengine.py release".
- **Microdata stay private.** No `.h5` file, record-level extract or weight is committed (`.gitignore`, `scripts/check_public_data.py`). `scripts/youth_base_check.py` prints weighted totals for the team only.
- **Columns the measures read:** `age`, `employment_status`, `current_education`, `is_in_approved_training`, `is_in_non_advanced_education`, `employment_income`, `self_employment_income`, `hours_worked`, `universal_credit_reported`, `is_disabled_for_benefits`, `pip_dl_category`, `pip_m_category`, `region`, `rent`, `tenure_type`.
- **Columns the measures need but the data lack:** work history, NEET status and duration, Work Capability Assessment outcome or UC conditionality group, care-leaver status, employer records and hiring flows. The pinned build stores `is_apprentice` only as a flag drawn at ages 21-24 for the employer NICs apprentice relief (about 214-237 records, about 130k people weighted): fit for a national score of that relief, about 28% short of HMRC (£0.27bn against £0.37bn in 2024-25), and not for describing apprentices, other ages or sub-national areas (#6).
- **Heavy runs.** Run one data-loading job at a time and check available memory first. Prefer reading the needed columns to full simulations.
